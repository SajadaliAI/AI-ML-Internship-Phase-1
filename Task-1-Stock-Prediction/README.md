# 📈 Stock Price Prediction using Machine Learning

This project focuses on analyzing historical stock market data and building a machine learning model to predict future stock prices.

The project was developed as part of the **DevelopersHub AI/ML Internship — Phase 1**.

---

## 🎯 Project Objective

The objective of this project is to explore historical stock price data, identify patterns and trends, and apply machine learning techniques for stock price prediction.
